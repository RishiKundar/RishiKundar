### 🌟 Featured Project

<table align="center" width="100%">
  <tr>
    <td width="100%">
      <h3>🚆 <a href="https://github.com/RishiKundar/train-booking-system">Distributed Train Reservation & Payment Platform</a></h3>
      <p>A production-grade, event-driven microservices platform (6 services) engineered to process high-concurrency ticket bookings with zero overselling, asynchronous Kafka ingestion, and automated payment settlement.</p>
      <ul>
        <li><b>Concurrency Engine:</b> Row-level pessimistic locking (<code>SELECT ... FOR UPDATE</code>) + idempotency key verification for zero race-condition guarantees.</li>
        <li><b>Event Pipeline:</b> Dual-write protection via after-commit transaction synchronization (<code>TransactionSynchronizationManager</code>) pushing to Kafka topics.</li>
        <li><b>Edge Gateway:</b> Reactive Spring Cloud Gateway with JWT authentication, RBAC, and Token-Bucket rate limiting via Bucket4j & Caffeine cache.</li>
        <li><b>Payment Lifecycle:</b> Razorpay integration with HMAC-SHA256 signature verification and automated inventory compensation on failed transactions.</li>
      </ul>
      <p><b>Tech:</b> <code>Java 21</code> • <code>Spring Boot 3</code> • <code>Apache Kafka</code> • <code>PostgreSQL</code> • <code>Docker</code> • <code>Razorpay</code> • <code>Bucket4j</code></p>
